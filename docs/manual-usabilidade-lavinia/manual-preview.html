Manual de usabilidade — Resultado Metas

Para: Lavínia Ferraz Crispim · Coordenadora · Reestruturação

Olá, Lavínia! Este guia mostra onde clicar e o que cada indicador significa na tela Resultado Metas Bismarchi Pires.

1. Entrar no sistema

1. Abra o link do SIOE.
2. E-mail: lavinia.ferraz@bismarchipires.com.br + senha recebida.
3. Clique em Entrar.

No primeiro acesso, use o aviso amarelo Alterar senha → para trocar a senha padrão.

2. Overview (visão consolidada)

Você cai direto nesta tela. Cada linha é um indicador; as colunas são os meses + Acum.

Onde clicar

  • 2026 / 2025 — ano de referência.
  • Abas — Overview = consolidado; demais = detalhe do KPI (na sua conta, o detalhe vem filtrado em Reestruturação).
  • Todos os meses / Resultado / Jan…Dez — período.
  • COPIAR — copia a grade para PowerPoint/e-mail.
  • Racional — lista das linhas que formam o %.

Verde = meta atingida   Vermelho = abaixo da meta   “-” = sem dado

3. Filtrar um mês

Clique em Jun (ou outro mês). A célula fica destacada e o Acum. reflete o filtro.
Resultado = período oficial da campanha (a partir de junho até o último mês fechado).

4. Racional (abrir o detalhe)

Na linha do indicador → Racional → confira Meta × Resultado e a tabela → Excel para exportar tudo → feche com X.

5. Aba de detalhe (ex.: SLA Protocolo)

Clique na aba SLA Protocolo. Aparecem cards, gráfico D-1 vs FATAL, justificativas e ranking de responsáveis. Use Racional / Copiar gráfico em cada bloco.
